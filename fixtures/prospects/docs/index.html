Getting started with the Quillmate SDK

This guide walks you through installing the SDK, creating an API key, and sending your first document to a reviewer in under ten minutes.

Install the SDK

The SDK supports Node.js 20 and later. Install it from the npm registry with your package manager of choice.

npm install @quillmate/sdk

If you deploy to a serverless platform, add the package to your production dependencies so it is bundled with your functions.

Create an API key

Open the dashboard, choose Settings and then API keys, and create a key scoped to the workspace you want to send documents from.

Store the key in an environment variable. Never commit it to source control or expose it in browser code.

Send your first document

Create a client with your key, upload a file, and request a review from one or more people by email address.

const quill = new Quillmate({ apiKey: process.env.QUILLMATE_KEY });
await quill.reviews.create({ file, reviewers: ['sam@example.com'] });

The call returns a review ID. Reviewers receive an email with a link that opens the document in the Quillmate viewer.

Listen for review events

Register a webhook endpoint to receive an event whenever a reviewer comments, approves, or requests changes on a document.

Each event is signed. Verify the signature header with your webhook secret before trusting the payload.

Troubleshooting

My request returns 401

Check that the API key belongs to the same workspace as the document and that it has not been revoked in the dashboard.

Reviewers never get the email

Ask reviewers to check their spam folder and add the Quillmate sending domain to their organization's allow list.
